Coding agent handoff

A free, MIT-licensed agent skill. Before you leave your computer or switch sessions, have your coding agent write a handoff that separates what it actually verified from what it did not. It depends on no other tool.

What the handoff contains

  • Changes: what the agent changed, and where.
  • Verified: the checks it ran, with their results.
  • Blocked or unverified: what it could not check, and why.
  • Next steps: what to do first when you pick the work up again.

Read the skill on GitHub and an example handoff.

Install

Claude Code: copy the skills/coding-agent-handoff folder to ~/.claude/skills/.
Codex: copy the same folder to ~/.codex/skills/.

Then tell the agent you are stepping away, or ask it to write a handoff.

Continue from your phone

Palmhelm syncs the agent sessions running in your Herdr panes to your iPhone and Mac, so a handoff written on your computer can be read on your phone, and you can keep messaging the agent from there. Palmhelm only supports agents running in Herdr panes. On the Mac it works through Palmhelm for Mac (Apple silicon, macOS 15 or later), the recommended way, or through the standalone Palmhelm Bridge for command-line users. Palmhelm home page
